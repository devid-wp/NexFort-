- Tag: `v7.0.9`

The original NexFort import omitted Git metadata for AyuGram submodules and
repository support files. They were restored without modifying the imported
source files.

The build is not verified yet. Repository agent policy prohibits agents from
building the project, so each developer must complete the platform-specific
Debug build and launch checks described in `CONTRIBUTING.md`.
